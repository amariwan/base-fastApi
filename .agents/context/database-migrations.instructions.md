# Database Migration Conventions

- Schema changes must be implemented via Alembic revisions under `alembic/`.
- Never run migrations implicitly during request handling or import.
- Inspect `alembic/env.py` and review autogenerated changes.
- Test migrations against the target database engine.
- Document transaction and compatibility implications.
