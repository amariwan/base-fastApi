# Task: Refactoring

## Schedule
- Repeat: on-demand

## Objective
Improve code structure without changing behavior.

## Steps
1. Establish test coverage for target area.
2. Identify code smells and boundaries.
3. Plan small vertical slices.
4. Refactor with tests green throughout.
5. Run `just check` and review diff.

## Output
- Refactor PR with rationale.
