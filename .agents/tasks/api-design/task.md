# Task: API Design Review

## Schedule
- Repeat: before adding/changing endpoints

## Objective
Ensure API changes are consistent and backward-compatible.

## Steps
1. Review route naming and HTTP methods.
2. Validate Pydantic schemas and error responses.
3. Check OpenAPI output.
4. Assess versioning/deprecation impact.
5. Update contract tests.

## Output
- API design review notes.
