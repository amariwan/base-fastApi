# Task: Incident Response

## Schedule
- Repeat: on-demand (when an alert fires)

## Objective
Triage and mitigate a production incident quickly and safely.

## Steps
1. Acknowledge alert; open incident channel.
2. Gather logs/metrics (observability stack, Sentry).
3. Identify blast radius and affected users/tenants.
4. Apply mitigation (rollback, feature flag, scale).
5. Communicate status updates.
6. Post-mortem within 48h with action items.

## Output
- Incident timeline + post-mortem doc.
