# Task: New Feature Development

## Schedule
- Repeat: on-demand

## Objective
Deliver a new feature end-to-end with tests and docs.

## Steps
1. Clarify requirements and acceptance criteria.
2. Design API contract (schemas, routes).
3. Implement domain/application/infrastructure layers.
4. Add tests (unit, integration, e2e).
5. Update docs and OpenAPI.
6. Run `just check`.

## Output
- Feature PR with tests and docs.
