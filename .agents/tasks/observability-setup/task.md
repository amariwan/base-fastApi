# Task: Observability Setup

## Schedule
- Repeat: on-demand (new service)

## Objective
Add logging, tracing, and metrics to a service.

## Steps
1. Add structured logging with correlation IDs.
2. Add tracing spans for use cases.
3. Define key metrics.
4. Add health/readiness checks.
5. Verify in staging.

## Output
- Observability checklist complete.
