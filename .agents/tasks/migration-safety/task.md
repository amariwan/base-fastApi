# Task: Migration Safety Check

## Schedule
- Repeat: before merging any PR touching `alembic/` or models

## Objective
Ensure database migrations are safe, reversible, and compatible.

## Steps
1. List new revisions: `alembic history`.
2. Review autogenerated diff for data loss / destructive ops.
3. Verify downgrade path (`alembic downgrade -1`) on a disposable DB.
4. Check for locks / long-running statements.
5. Confirm `DB_AUTO_CREATE_TABLES` not relied upon.
6. Run integration tests against a migrated DB.

## Output
- Migration review notes + rollback plan.
