# Task: Onboarding Check

## Schedule
- Repeat: on-demand (new contributor)

## Objective
Verify a new contributor can set up and run the project.

## Steps
1. Follow README setup from scratch in a clean clone.
2. Run `just dev`, `just test`, `just lint`, `just mypy`.
3. Confirm `.env.example` covers all required vars.
4. Check docs/ for gaps.
5. Report friction points.

## Output
- Onboarding feedback report.
