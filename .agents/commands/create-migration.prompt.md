argument-hint: 'model-or-schema-change'
user-invocable: true
---

You will guide the user through creating a safe Alembic migration.

1. Ask which model/schema change is needed.
2. Inspect `alembic/env.py`, `alembic.ini`, and `src/app/core/core_db/`.
3. Propose the migration command and revision message.
4. Remind to review autogenerated output and test against the target engine.
5. List validation commands (`just test-integration`, `just lint`).
