argument-hint: 'pr-number-or-diff'
user-invocable: true

You will review a pull request or diff.

1. Ask for the PR number or paste the diff.
2. Check architecture boundaries, security, tests, migrations.
3. List findings by severity with file/line references.
4. Suggest focused validation commands.
5. Summarize approval status.
